What This System Does\n\n- **Backup (ops:backup)**: Creates timestamped ZIP checkpoints of critical project files + user config (~24h schedule)\n- **Health Check (ops:health-report)**: Probes configured endpoints, reports latency/status (~15min schedule)\n- **Restore Validation (ops:restore-test)**: Extracts and validates latest checkpoint integrity (~weekly schedule)\n- **Scheduler**: Automates all operations via Windows Task Scheduler or cron\n\n**Outputs:**\n- Checkpoints: `{{PROJECT_ROOT}}/output/shared/checkpoints/checkpoint-YYYYMMDD-HHMMSS.zip`\n- Health reports: `{{PROJECT_ROOT}}/output/results/ops-health-latest.json`\n- Logs: Console output, stored in Task Scheduler history (Windows) or syslog (Unix)\n\n---\n\n## 2. Troubleshooting\n\n### Backup fails: \"Permission denied on directory\"\n\n**Solution:**\n- Ensure script runs with elevated privileges (Windows) or sudo (Linux)\n- Check paths in `includePaths` exist and are readable\n- Verify `output/shared/checkpoints` directory has write permissions\n\n### Health check always fails\n\n**Solution:**\n- Verify endpoint URLs are correct: `http://127.0.0.1:PORT/healthz`\n- Increase `endpointTimeoutSec` if network is slow\n- Check if service is actually running: `curl http://127.0.0.1:PORT/healthz`\n- Look at PowerShell error log: `Get-EventLog -LogName \"Windows PowerShell\" -Newest 10`\n\n### Restore validation fails: \"manifest.json not found\"\n\n**Solution:**\n- Old backups may not have manifest.json\n- Delete old checkpoints, create fresh backup: `npm run ops:backup`\n- Set `keepExtractedOnFailure: true` in config to inspect ZIP contents\n\n### Task Scheduler task doesn't run\n\n**Solution:**\n```powershell\n# Check task exists:\nGet-ScheduledTask | Where-Object TaskName -like \"*apis*\"\n\n# View last run result:\nGet-ScheduledTaskInfo -TaskName \"my-api-ops-backup\"\n\n# Trigger manually:\nStart-ScheduledTask -TaskName \"my-api-ops-backup\"\n\n# View logs:\nGet-WinEvent -FilterHashtable @{LogName=\"Microsoft-Windows-TaskScheduler/Operational\"; Level=2}\n```\n\n---\n\n## 8.
