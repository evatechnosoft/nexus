# Strateji 3: Ücretsiz Araçlar (Lead Generation)

Huni girişi (Lead magnet) olarak ücretsiz hesaplayıcı, analizci veya derecelendirme aracı.

## Viral Döngü
- "Siteniz 100 üzerinden 43 puan" -> Değer alımı.
- Veri alımı (E-posta, telefon).
- Kullanıcı paylaşımı -> Viral büyüme.
- Ücretli sürüme yükseltme (Upsell).
